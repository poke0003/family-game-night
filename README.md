# Family Game Night

A shared lobby where family members (and AI players) start and play board and card games together in the browser, on phones or desktops.

The published site is these three files as they are: `index.html`, `app.js`, `games.js`. There is no build step. Lobby and game state are kept in a Firebase Realtime Database; the family passcode lives in that database's rules, not in this repository.
